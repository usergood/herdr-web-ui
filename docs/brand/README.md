# Project artwork

The fork's bundled artwork comes from [saurons-eye.svg](../../public/icons/saurons-eye.svg)
and [saurons-eye-badge.svg](../../public/icons/saurons-eye-badge.svg): an amber eye
and a white-on-transparent notification badge. The original supplied ram artwork in
`icon-source.png` remains as upstream provenance; it is not the fork's export source.

Run `bun scripts/generate-brand.ts` to regenerate the app icons, favicon,
Apple touch icon and social preview. This optional asset task uses the project's
Playwright Chromium installation and requires no FFmpeg or extra font package.
Maskable icons have an opaque background and keep the eye inside the central safe zone.
When regenerating changed artwork, update the icon URL queries and service-worker
cache name together; see [installation and notification setup](../pwa-installation.md).

The [social preview](../../public/social-preview.png) is 1280 × 640 PNG,
under 1 MB. The website uses `public/social-preview.png` for its Open Graph image.
The retained banner `docs/media/banner.png` and alternate preview `site/assets/og.png`
are generated by `scripts/readme-media/banner.ts`. GitHub's repository preview is a
separate setting: open [repository settings](https://github.com/usergood/herdr-web-ui/settings),
then **Social preview → Edit → Upload an image** and select that file.
See [GitHub's instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
