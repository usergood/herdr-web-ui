# Reuse approved issue scope for implementation

An independently deliverable GitHub issue maps to one Assignment, while Tickets remain bounded internal work. Projects can opt into automatic implementation of trusted agent-ready issue revisions, reusing applicable planning and testing approvals while retaining checks and independent Standards and Spec reviews. This avoids planning the same work twice; it requires revision-bound readiness, explicit dependencies and a controlled pause when accepted scope changes, instead of treating any ready label as unlimited authority.
