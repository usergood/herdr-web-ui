# Bind Human Review approval to its repair lineage

The owner wants approval to finish the submitted repairs and merge: Approve without comments authorizes the valid checked/reviewed candidate; Approve with comments conditionally authorizes that exact batch's in-scope repairs and merge after fresh checks and independent Standards/Spec review, without a second human gate. Decline grants no merge authority and returns repaired work to the same Human Review conversation for approval; preserving revision/comment lineage prevents unrelated changes from inheriting authorization while permitting approved fixes to change the head. Specifications owns interview/to-spec, Orchestrator owns automatic execution/repairs, and fresh Human Review fixes preserve their separate provenance; see the [accepted design](../factory/automatic-dispatch-pause-delete-design.md), an implementation target that leaves release/deployment authority separate.
