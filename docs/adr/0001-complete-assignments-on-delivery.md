# Complete Assignments on verified delivery

An Assignment with repository changes becomes Done when verified PR merges cover its intended changes, followed by a containing release if its frozen Project policy requires one. Research without repository changes can be accepted manually; Discard finishes work with a distinct outcome while retaining its history. This replaces completion at implementation acceptance so the board reflects delivery, at the cost of tracking delivery evidence and reconciling unarchived historical Done records.

The retained-history Discard clause is superseded by [ADR 0004](0004-separate-pause-from-permanent-deletion.md); the verified-delivery criteria remain applicable. [ADR 0005](0005-bind-human-review-approval-to-repair-lineage.md) defines conditional Human Review merge authority. These accepted changes remain implementation targets until delivered.
